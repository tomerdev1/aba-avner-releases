# Aba Avner — Releases

Public installer downloads and update manifests for [Aba Avner](https://github.com/tomerdev1/Aba-Avner).
Source code lives in the private `tomerdev1/Aba-Avner` repo — this repo holds only
release binaries and the `latest.json` update manifest, so they can be fetched
without exposing the source.
